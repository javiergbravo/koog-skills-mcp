## Overview

With the introduction of JSON schema capabilities for OpenAI models in Koog v0.8.0, developers can now leverage structured output formats to enhance data validation and ensure consistency in model responses. This feature allows for the definition of expected data structures, making it easier to work with the outputs of OpenAI models.

## Code Examples

### Defining a JSON Schema

To define a JSON schema for an OpenAI model output, you can create a schema that specifies the expected structure of the response.

```kotlin
val jsonSchema = """
{
  "\$schema": "http://json-schema.org/draft-07/schema#",
  "type": "object",
  "properties": {
    "id": {
      "type": "string"
    },
    "object": {
      "type": "string"
    },
    "created": {
      "type": "integer"
    },
    "choices": {
      "type": "array",
      "items": {
        "type": "object",
        "properties": {
          "text": {
            "type": "string"
          },
          "index": {
            "type": "integer"
          }
        },
        "required": ["text", "index"]
      }
    }
  },
  "required": ["id", "object", "created", "choices"]
}
""".trimIndent()
```

### Validating Model Output Against the Schema

Once you have defined a JSON schema, you can validate the output from an OpenAI model against this schema.

```kotlin
val modelOutput = openAiModel.generateResponse(prompt)
val isValid = validateJsonAgainstSchema(modelOutput, jsonSchema)

if (isValid) {
    println("Model output is valid according to the schema.")
} else {
    println("Model output does not conform to the schema.")
}
```

## Key Concepts

- **JSON Schema**: A powerful tool for validating the structure of JSON data. It allows you to define the expected format, types, and constraints for your data.
- **Model Output Validation**: Ensures that the responses generated by OpenAI models adhere to the defined schema, reducing errors and improving data integrity.
- **Structured Outputs**: By utilizing JSON schemas, developers can work with structured outputs that are easier to manipulate and understand, leading to better integration with other systems and components.
